## 用法

```tsx
import { ColorPicker } from "@/components/ui/color-picker/color-picker"

export function BrandColor() {
  return <ColorPicker label="主色" defaultValue="#2563eb" />
}
```

HEX 段可直接输入或粘贴带或不带 `#` 的 3、6 位颜色，开启 `alpha` 时还接受 4、8 位，失焦或回车时规范化。非法内容保留为草稿并提示错误，不覆盖有效值；关闭面板时丢弃无效草稿，回到当前颜色。用 `value` 与 `onValueChange` 控制颜色，用 `onValueCommit` 保存操作结束时的值。

### 值与格式

输出始终为小写 `#rrggbb`，`alpha` 开启时输出 `#rrggbbaa`。`format` 设置面板初始格式，面板切换 HEX、RGB、HSL 不改变输出格式。内部 HSV 浮点状态会保留灰度颜色此前的色相。

### 独立部件

组件文件还导出 `ColorArea`、`ColorHueSlider`、`ColorAlphaSlider`、`ColorSwatch`。`ColorArea` 接收 HSV 对象与 `onValueChange` / `onValueCommit`；两个滑条接收数字值，色相范围 0–360，透明度范围 0–1，透明度条额外接收 HSV `color`。色块接收 CSS 颜色 `color`。各部件支持 `className`。

`ColorPickerProps`、`ColorPickerLabels` 为主组件类型。颜色工具独立安装 `color` 条目，导出 `RGB`、`HSV`、`HSL` 类型和 `parseHex`、`rgbToHex`、`rgbToHsv`、`hsvToRgb`、`hsvToHsl`、`hslToHsv`、`rgbToHsl`、`hslToRgb`、`clamp`。RGB 通道范围 0–255，色相为度，其余通道为 0–1。

| data-slot | 用途 |
| --- | --- |

| color-picker-panel | 面板内容 |

## 可访问性

二维区有两个视觉隐藏的原生 range，分别读出饱和度与明度。方向键每次调整 1%，Shift + 方向键调整 10%，Home / End 跳到两端。色相和透明度使用 Base UI Slider，提供中文值描述。Tab 聚焦有可见焦点环，Escape 关闭弹层。触屏使用带安全区的底部 Sheet。

## 注意事项

吸管仅在浏览器提供 EyeDropper 时显示，取消不改变颜色。`labels` 可覆盖中文文案。`name` / `form` 提交规范化颜色，非受控模式支持表单重置。`disabled` / `readOnly` 阻止修改。

颜色工具单元测试：`pnpm exec tsx --test scripts/color.test.ts`。

禁用或只读时会关闭已打开的弹层和触屏面板，重新启用不会自动打开；之后不再触发颜色变化或提交回调。

触屏底部面板的根节点是 `data-slot="color-picker-sheet"`，点外部收起之类的逻辑可以用 `closest` 识别它。
