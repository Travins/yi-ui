## 用法

```tsx
import { GridPagination } from "@/components/ui/grid-pagination/grid-pagination"

;<GridPagination defaultPage={1} pageCount={13} total={128} />
```

整条是一行格子，格子之间用虚线分开，没有圆角。哪些格子出现取决于**分页条自己的宽度**（容器查询，不是屏幕宽度）：

| 格子                    | 宽于 44rem | 36rem – 44rem | 窄于 36rem                                             |
| ----------------------- | ---------- | ------------- | ------------------------------------------------------ |
| 信息格                  | 显示       | 显示          | 独占上一行                                             |
| 每页条数（`pageSizes`） | 显示       | 显示          | 隐藏                                                   |
| 首页、上一页            | 显示       | 显示          | 显示                                                   |
| 页码                    | 显示       | 显示          | 收成一格「当前页 / 总页数」                            |
| 下一页、尾页            | 显示       | 显示          | 显示                                                   |
| 跳页（`jumper`）        | 输入框     | 隐藏          | 点「当前页 / 总页数」就地换成输入框（`compactJumper`） |

各格内容：信息格占满剩余宽度，传 `total` 时显示「01–10 / 128」，否则显示「当前页 / 总页数」，`info` 可换成任意内容；每页条数是官方 Select，触发器铺满整格；页码每个一格，当前页整格铺主题色（`primary`）。

底层是官方 `Pagination`、`PaginationContent`、`PaginationItem`、`PaginationLink`，读屏与键盘行为和官方一致。传 `getHref` 时每一格都是真实链接；不传时是按钮，只发出 `onPageChange`。`pageSize` 由调用方控制，改变时应同步更新 `pageCount` 与 `page`。

### 页码算法

页码排布放在 `lib/pagination-slots.ts`（随组件一起安装）：`getPaginationSlots` 算出固定数量的槽位，`getPaginationRange` 算出当前页的条目范围。自己做分页外观时可以直接复用。

### 窄屏跳页

开了 `jumper` 后，窄于 36rem 时中间的「当前页 / 总页数」是一个按钮，读屏读作「3 / 13，跳转到指定页」。点它，这一格就地换成数字输入框（右边保留「/ 总页数」，占位是当前页）：回车跳转并把焦点还给按钮，Esc 取消并还焦点，点别处失焦也会取消，输入不是数字时回车无反应、输入框保持打开。输入框在触屏上是 16px，不会触发 iOS 放大。

这个功能跟随 `jumper` 默认开启：已经开了 `jumper` 的使用方，窄屏会多出这个入口，而宽容器的外观不变。不想要时传 `compactJumper={false}`。总页数只有 1 时没有入口。36rem – 44rem 之间页码还在、跳页输入框还没出现，这一段不提供跳页。

### 外框

单独使用时整条带一圈边框（`bordered` 默认为 `true`）。放进已经有边线的容器，例如表格底部，设 `bordered={false}`，由容器画顶部横线，左右与底边沿用容器的外框，看上去就是表格的最后一行。

| --------------- | ------------------------------ |

根元素在 `bordered` 为真时带 `data-bordered`。

## 可访问性

根元素是带名称的导航（默认「分页」）。页码有「第 N 页」名称，当前页带 `aria-current="page"`；首页、上一页、下一页、尾页都有名称，到头时禁用。每页条数与跳页输入有可访问名称。窄容器里的「当前页 / 总页数」在开了 `jumper` 时是按钮（名称「3 / 13，跳转到指定页」，可用 `labels.jumpTrigger` 覆盖），旁边有一个读屏专用的 `aria-live` 区域，翻页时会读出；没开 `jumper` 时它本身就是 `aria-live` 区域。焦点环画在格子内侧，不会被相邻格子遮住。所有内置文案可通过 `labels` 覆盖。

## 注意事项

格子高度对应按钮的 `icon` / `icon-lg` 档：`size="sm"` 为 32px，默认 36px，触屏上分别加高到 40 / 44px。页码采用固定槽位：总页数多于 `siblings × 2 + 5` 时，无论当前在第几页，页码格（含省略号）的数量都相同，翻页时整条不抖动。页码格按位置渲染，翻页时格子本身不重建：格里的数字顺着翻页方向滚动（往后翻向左、往前翻向右），当前页的主题色块用 Motion 共享布局滑到新位置；系统开启「减少动态效果」时直接切换。`pageCount` 至少按一页显示，`page` 超出范围时夹到有效范围。
