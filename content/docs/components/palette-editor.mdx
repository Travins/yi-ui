## 用法

```tsx
import { PaletteEditor } from "@/components/ui/palette-editor/palette-editor"

export function SeriesColors() {
  return <PaletteEditor defaultValue={["#172554", "#38bdf8", "#fef3c7"]} />
}
```

用 `value` / `onValueChange` 控制 HEX 数组，`onValueCommit` 在编辑结束、增删、排序或选择预设时触发。列表上方的色带按当前色觉视角显示整组颜色，切换视角就能直接对比；每行的 HEX 始终是原色。新增颜色时在末项基础上旋转色相，避免和已有颜色撞色。

### 自定义检查规则

项目已有自己的配色规则时，用 `findConflicts` 替代内置检查，让提示和项目其他地方的检查来自同一个函数。传入后 `threshold` 不再生效。函数在颜色每次变化时都会运行，不要放耗时操作；返回值里的 `a`、`b` 是从 0 开始的颜色索引。

## API

<PropsTable name="palette-editor" component="PaletteEditor" />

导出 `PaletteEditorProps` 和 `PaletteEditorLabels`。`labels` 可覆盖文本及 `color(n)`、`moved(n,m,k)`、`conflict(a,b,vision,deltaE)` 格式函数。

`labels.up`、`down`、`remove` 和 `openColor` 接受字符串或 `(n: number) => string`，序号从 1 开始。默认是「上移第 N 个颜色」「下移第 N 个颜色」「删除第 N 个颜色」「选择第 N 个颜色」，读屏能分清是哪一行。

| data-slot | 用途 |
| --- | --- |
| palette-editor | 根容器 |
| palette-editor-list | 有序列表 |
| palette-editor-item | 色卡行 |
| palette-editor-preview | 当前视角色带 |
| palette-editor-swatch | 色带中的单个颜色 |
| palette-editor-conflicts | 冲突提示 |
| palette-editor-announcement | 排序播报 |

## 可访问性

每行的序号是颜色输入的可见标签（读屏读作「颜色 N」），排序、删除按钮常显。按钮聚焦时 Alt + ↑ / ↓ 排序；输入框及弹层内不拦截快捷键。排序保留行的稳定 key，并用 polite 实时区域播报位置。有冲突的行在序号旁显示警示图标（附屏幕阅读器文字），冲突明细以文字列在列表下方，不只靠颜色表达。

## 注意事项

`name` / `form` 用隐藏输入提交 JSON 字符串数组，非受控表单支持 reset。`disabled` 不提交字段，`readOnly` 保留提交但禁止编辑。外部传入的数组应为有效 HEX，且数量在上下限内。默认最少 1 项、最多 12 项，阈值 10。

色觉模拟用于辅助检查，不代表所有人的实际感知；ΔE00 也不等同于文字对比度合规。

禁用或只读时会关闭行内取色面板，之后不再触发颜色提交。
