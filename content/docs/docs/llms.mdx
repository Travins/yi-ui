## llms.txt

站点按 [llms.txt](https://llmstxt.org) 约定提供两个纯文本入口：

- [`/llms.txt`](https://yiui.dev/llms.txt)：站点简介、安装方式、组件清单与文档链接。适合当作索引喂给模型。
- [`/llms-full.txt`](https://yiui.dev/llms-full.txt)：全部文档与博客的 MDX 原文。适合一次性放进上下文。

两个文件都在构建时生成，内容与页面保持一致。

## Agent 技能

给 Agent 装上 Yi UI 技能后，它会知道怎么选条目、怎么安装，以及导入路径、按钮高度、方条控件这些容易写错的地方：

```bash title="终端"
npx skills add Travins/yi-ui --skill yi-ui
```

技能只面向使用组件的项目。需要细节时，它会读每个条目的 Agent 版文档，例如 [`/md/components/number-stepper.md`](https://yiui.dev/md/components/number-stepper.md)，里面已经展开了示例代码和属性表。

Agent 发现组件有问题时，技能会让它先告诉你，经你同意再提 [issue](https://github.com/Travins/yi-ui/issues)。

## 在 AI 编辑器中使用

最简单的方式：让 Agent 先读 `https://yiui.dev/llms.txt`，从中找到组件清单和每个条目的 JSON 地址，再按[安装](/docs/installation/)页里的命令运行。

向 Agent 提需求时，建议明确写出：

- 使用 Yi UI 的哪个条目，例如「用 `@yiui/grid-layout` 搭页面骨架」。
- 项目要先按[安装](/docs/installation/)初始化 shadcn，底座选 Base UI；让 Agent 先看 `components.json` 的 `style` 是否以 `base-` 开头。
- 安装前先加 `--dry-run` 看会写入哪些文件，已有同名文件默认不要覆盖。
- 颜色只用主题变量，不要硬编码。
- 安装后源码属于项目，可以按需修改。

如果 Agent 的运行环境设置了 SOCKS 代理（`ALL_PROXY`），shadcn CLI 可能以 `other side closed` 失败，让它用 `env -u ALL_PROXY -u all_proxy` 去掉该变量再运行，详见[安装](/docs/installation/#常见问题)。

## shadcn MCP

shadcn 官方提供 MCP 服务，可以让 AI 编辑器直接检索和安装 Registry 里的条目。`@yiui` 已在 shadcn 官方目录里，不用额外配置命名空间（见 [Registry 与命名空间](/docs/registry/)），直接初始化 MCP：

```bash title="终端"
pnpm dlx shadcn@latest mcp init --client claude
```

`--client` 可选 `claude`、`cursor`、`vscode`、`codex` 等。也可以手动写配置，例如 Claude Code 的 `.mcp.json`：

```json title=".mcp.json"
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

配置完成后，可以直接这样对 Agent 说：

- 「列出 @yiui 里所有组件」
- 「把 @yiui/auth-01 加到项目里」
