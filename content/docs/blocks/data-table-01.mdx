## 功能说明

管理数据集列表，支持当前页选择、固定名称列、列宽调整、三档密度、搜索与状态筛选。示例数据均为虚构。

### 用到的组件

| 组件                      | 用途                                                               |
| ------------------------- | ------------------------------------------------------------------ |
| grid-layout               | 页面外框：竖线容器、全屏横线与点阵分隔带                           |
| checkbox / button / input | 选择、操作与编辑                                                   |
| grid-toolbar              | 顶部工具栏：搜索、筛选、列设置、密度各占一格                       |
| bar-field                 | 搜索输入与快捷键提示                                               |
| bar-select                | 状态筛选与负责人多选筛选                                           |
| grid-pagination           | 底部翻页条：范围、每页条数、首尾页和跳页，与表格之间隔一条点阵小带 |
| segmented-control         | 密度选择（只显示行数图标，在工具栏里是三个方格）                   |
| alert-dialog              | 单行与批量删除确认                                                 |
| dropdown-menu             | 列设置与窄屏排序菜单                                               |
| empty / skeleton          | 空状态与加载                                                       |
| sheet                     | 桌面右侧详情、手机底部详情与编辑面板                               |

## 用法

```tsx
"use client"
import { DataTable } from "@/components/data-table-01/data-table"
const columns = [{ accessorKey: "name", header: "名称" }]
const data = [{ id: "1", name: "城市声景" }]
export default function Page() {
  return <DataTable columns={columns} data={data} getRowId={(row) => row.id} />
}
```

### 客户端与服务端模式

默认 `mode="client"` 在本地排序、筛选和分页。`mode="manual"` 时由使用方响应 `onSortingChange`、`onGlobalFilterChange`、`onColumnFiltersChange` 和 `onPaginationChange`，请求后更新 `data` 与 `rowCount`。请求期间传 `loading`，失败传 `error` 和 `onRetry`。

### 编辑与失败回滚

列 `meta.editable` 支持 `text` 与 `number`。编辑框就地替换内容，整格描主色实线框，下方贴一条提示条显示快捷键；`meta.validate(value, row)` 返回错误文字时提示条变红，编辑态保留。

`onCellCommit({ rowId, columnId, value, row })` 可以返回 Promise。保存是乐观的：编辑框立刻关闭，格子右上角显示「保存中」，成功后显示「已保存」并淡出；Promise 拒绝时值回滚，格子标红，悬停或聚焦可看到错误，按 Enter 重新编辑会带回草稿。值没有变化时不会调用 `onCellCommit`。父层应在保存成功后同步数据；编辑使用 accessorKey 对应的顶层字段。示例模拟 600ms 请求，改成已有的名称会被拒绝。

### 行操作与主动编辑

通过 `apiRef` 获取 `DataTableHandle`，调用 `startEditing(rowId, columnId)` 开始单元格编辑，调用 `openDetails(rowId)` 打开详情。桌面详情从右侧展开，手机从底部展开。

```tsx
import { DataTableRowActions } from "@/components/data-table-01/data-table-row-actions"

;<DataTableRowActions
  label={row.name}
  actions={[
    { label: "查看详情", onSelect: () => apiRef.current?.openDetails(row.id) },
    {
      label: "编辑名称",
      onSelect: () => apiRef.current?.startEditing(row.id, "name"),
    },
    "separator",
    { label: "删除…", destructive: true, onSelect: () => setDeleting([row]) },
  ]}
/>
```

按钮的读屏名称默认是 `"{name} 的操作"`（`{name}` 为行名称）。要改，可以传完整的 `ariaLabel`（字符串，或接收 `label` 的函数），也可以只改模板：`labels={{ rowActions: "{name} 的操作" }}`，`{name}` 会替换成 `label`。`ariaLabel` 优先于模板。

每项可传 `icon`、`shortcut`；`"separator"` 插入分隔线。示例提供查看、编辑、复制编号、导出 CSV、归档与删除。删除和批量删除先确认，复制结果由读屏提示。选中行内控件后按 Shift+F10 或 ContextMenu 键打开该行菜单。

窄于 40rem 时搜索格独占一行，状态筛选在下一行与列设置、排序同排，隐藏色点和数量以保留完整状态文字；隐藏密度选择，给搜索与筛选留出空间。虚拟滚动仅显示总行数。

### 负责人筛选

示例通过 `toolbar={(table) => ...}` 插槽接入方条多选：插槽里的控件包一层 `GridToolbarItem` 成为工具栏的一格，用 owner 列的 `filterFn` 匹配选中负责人，更新筛选后回到第一页。每位负责人的计数来自完整数据集；窄容器隐藏此筛选。

### 外部筛选与「清除筛选」

服务端分页时，筛选状态往往放在页面里（比如 `toolbar` 插槽中的下拉），表格自己的搜索和列筛选里看不到它。传 `filtered` 告诉表格「外部筛选正在生效」：没有结果时空状态显示「没有符合条件的结果」和「清除筛选」。点击时表格先清掉自己的搜索与列筛选，再调用 `onClearFilters`，由你重置外部筛选。桌面表格和手机列表的空状态都是如此。

```tsx
const [owner, setOwner] = React.useState<string | null>(null)

;<DataTable
  mode="manual"
  columns={columns}
  data={pageRows}
  rowCount={total}
  getRowId={getRowId}
  filtered={!!owner}
  onClearFilters={() => setOwner(null)}
  toolbar={
    <GridToolbarItem className="w-36">
      <BarSelect
        aria-label="负责人"
        value={owner}
        onValueChange={setOwner}
        options={owners}
      />
    </GridToolbarItem>
  }
/>
```

### 列表的读屏名称

桌面 `table` 与手机 `ul` 的 `aria-label` 默认取 `labels.dataset`（「数据列表」），不再复用搜索框的占位文案。同一页有多张表时，用 `ariaLabel="用户列表"` 给每张表各起一个名字，它优先于 `labels.dataset`。

### 窄容器规则

表格和分页都按**容器宽度**而不是屏幕宽度切换：

| 部位                 | 宽于 44rem | 40rem – 44rem | 36rem – 40rem              | 窄于 36rem                        |
| -------------------- | ---------- | ------------- | -------------------------- | --------------------------------- |
| 表格主体             | 表格       | 表格          | 卡片列表                   | 卡片列表                          |
| 工具栏：搜索格       | 固定宽度   | 固定宽度      | 有状态筛选或插槽时独占一行 | 同左                              |
| 工具栏：密度选择     | 显示       | 显示          | 隐藏                       | 隐藏                              |
| 工具栏：排序菜单     | 隐藏       | 隐藏          | 显示                       | 显示                              |
| 分页：每页条数、页码 | 显示       | 显示          | 显示                       | 隐藏，页码收成「当前页 / 总页数」 |
| 分页：跳页           | 输入框     | 隐藏          | 隐藏                       | 点「当前页 / 总页数」就地输入     |

窄于 36rem 的分页里，信息格独占上一行。「当前页 / 总页数」是一个按钮，点开变成数字输入框，回车跳转、Esc 取消，细节见[网格分页](/components/grid-pagination/)。

## API

`columns`、`data`、`getRowId` 必填。排序、分页、全局筛选、列筛选、行选择均支持受控值、对应 `default*` 初值与 `on*Change` 回调。分页默认每页 10 条。

`filtered` 与 `onClearFilters` 见「外部筛选与清除筛选」，`ariaLabel` 见「列表的读屏名称」。搜索框默认只显示图标，读屏名称取 `labels.searchField`；传 `searchLabel="搜索"` 可在图标前显示条内标签。`statusFilter={{ columnId, options }}` 在搜索框右侧显示状态下拉（方条下拉，选项带色点和数量，清除即全部），空字符串表示全部，它的 `label` 作为未选时的占位（如「全部状态」，不传时取 `labels.all`），`tone` 设置色点颜色（如 `"var(--flow-green)"`）。`toolbar`、`bulkActions(selected)`、`rowActions(row)` 提供操作插槽；`bulkActions` 里的按钮文字包在 `<span data-label>` 中，窄容器只显示图标，`header` 可传入头部内容。manual 模式使用 `counts` 传入状态计数。`onSelectAll` 由使用方处理跨页全选，表头只选择当前页。`labels` 覆盖文案，其中 `dataset` 是列表名称、`rowActions` 是行操作按钮的名称模板、`jumpInput` 与 `jumpTrigger` 是跳页的读屏名称。

列 meta 支持 `align`、`editable`、`validate`、`hideOnMobile`、`pinned`、`bar`（数字比例条）、`max`（服务端模式的列最大值），列宽使用原生 `size`。`detailCell(value, row)` 定制详情字段的展示，例如完整时间。首个标记 pinned 的可见数据列固定。

文件职责：`data-table.tsx` 组装，`use-data-table.ts` 状态与 TanStack Table 装配，`data-table-grid.tsx` 桌面表格，`data-table-list.tsx` 窄屏卡片列表，`data-table-detail.tsx` 行详情抽屉，`data-table-bulk-bar.tsx` 批量操作条，`data-table-toolbar.tsx` 工具栏，`data-table-pagination.tsx` 分页，`data-table-cell.tsx` 编辑，`types.ts` 类型，`config.ts` 文案与常量。根节点为 `data-slot="data-table"`，滚动容器为 `data-table-scroll`，编辑格为 `data-table-cell`。

## 可访问性

| 按键              | 操作                              |
| ----------------- | --------------------------------- |
| Tab               | 聚焦排序、选择、编辑格与列宽手柄  |
| Enter / F2 / 双击 | 开始编辑                          |
| Enter             | 保存并聚焦下一行同列              |
| 点击别处          | 保存                              |
| Tab / Shift+Tab   | 保存并聚焦下一个 / 上一个可编辑格 |
| Esc               | 放弃修改                          |
| ← / →（列宽手柄） | 调整 16px                         |

表头提供 aria-sort，虚拟行提供 aria-rowindex，编辑错误通过 aria-describedby 关联。

## 注意事项

Table 固定使用 v8 API，调用函数添加 `"use no memo"`，避免 React Compiler 缓存稳定可变对象读取。虚拟滚动建议固定行高。不提供多格粘贴、撤销与方向键网格导航。
